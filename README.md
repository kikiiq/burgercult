# Burger Cult

A fictional burger restaurant website with a dark, occult-themed look (black, red and cream), built as a learning project with the help of Claude AI (Anthropic).

Fikcyjna strona restauracji z burgerami w mrocznym, okultystycznym stylu (czerń, czerwień, krem), stworzona jako projekt do nauki z pomocą Claude AI (Anthropic).

## Features / Funkcje

- Polish / English language switch (saved in the browser) / Przełącznik PL/EN (zapamiętywany w przeglądarce)
- Live restaurant status: open/closed, occupied tables shown as hearts, estimated wait time (simulated demo data) / Status na żywo: otwarte/zamknięte, zajęte stoliki jako serduszka, czas oczekiwania (dane demonstracyjne)
- Menu with tabs, prices formatted per language / Menu z zakładkami, ceny formatowane zależnie od języka
- Interactive burger builder with an animated SVG burger, live price, "roll the dice" and an achievement / Interaktywny kreator burgera z animowanym SVG, ceną na żywo, losowaniem i osiągnięciem
- Hidden menu: Konami code on desktop, tap the logo 5 times on mobile / Sekretne menu: kod Konami na komputerze, 5 dotknięć logo na telefonie
- About section, stylised SVG map, contact details, footer / Sekcja O nas, mapka SVG, dane kontaktowe, stopka

## Tech / Technologie

Plain HTML, CSS and JavaScript in a single file, no dependencies. The only external resource is the Pirata One font from Google Fonts.

## Run locally / Uruchomienie

Open `index.html` in a browser. / Otwórz `index.html` w przeglądarce.

## Publish with GitHub Pages / Publikacja

Repository Settings, Pages, deploy from the `main` branch, root folder. / Ustawienia repozytorium, Pages, wdrożenie z gałęzi `main`, folder główny.

## Note / Uwaga

The restaurant, address, phone number and e-mail are fictional. / Restauracja, adres, telefon i e-mail są fikcyjne.
